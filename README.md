# Daniel's portfolio

A responsive, static portfolio built with HTML, CSS, and a small copyright-year script. No build step or dependencies are required.

## Preview

Open `index.html` in a browser, or serve this directory with any static web server. `portfolio.html` is retained as a compatible entry point and contains the same page.

## Edit

Update the biography, project links, skills, and contact details directly in `index.html`. Keep `portfolio.html` in sync when making edits. The portrait is `boss.jpeg`. Project illustrations are decorative CSS compositions, not application screenshots.

## Publish

The root `index.html` works with GitHub Pages and other static hosts. Google Fonts is optional; system fonts are used if it is unavailable.
